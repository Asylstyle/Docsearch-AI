# Демо DocSearch AI — 1–2 минуты

Видео пока не записано. Ниже воспроизводимый сценарий, не отчёт о съёмке.
Для записи используйте отдельную демо-базу и публичный PDF из корпуса,
не личные документы. Не удаляйте существующие документы пользователя.

| Время | Экран / действие | Что объяснить |
|---|---|---|
| 0–15 с | Открыть localhost:8000/docs и GET /health | FastAPI, PostgreSQL16/pgvector, локальный CPU |
| 15–35 с | POST /documents, hse-dormitory-2017.pdf; GET /documents | Получить новый id, ready, pages_count=21; пустые страницы не сдвигают нумерацию |
| 35–55 с | GET /search, вопрос о часах тишины в общежитии ВШЭ, k=5 | Проверить filename и исходную page=7; показать страницу локального PDF, текст источника и JSON |
| 55–85 с | POST /ask с тем же вопросом | Сейчас без ключа: честно показать 503. Живой ответ с [n] и SourceRef допускается только после отдельного разрешения API и безопасной настройки |
| 85–100 с | Вопрос про пароль Wi-Fi из правил общежития | Отказ при найденных, но не отвечающих фрагментах требует LLM и сейчас не проверен. Не выдавать 503 за корректный отказ |
| 100–120 с | README, test-таблица, pytest | E5 выбран по dev; финальный test один раз; 8 офлайн-проверок; generation/judge NOT RUN |

Команды поиска и вопросов:

~~~sh
curl -G http://localhost:8000/search --data-urlencode "q=В какие часы в общежитии ВШЭ нужно соблюдать тишину?" --data-urlencode "k=5"
curl -X POST http://localhost:8000/ask -H "Content-Type: application/json" -d '{"question":"В какие часы в общежитии ВШЭ нужно соблюдать тишину?","k":5}'
curl -X POST http://localhost:8000/ask -H "Content-Type: application/json" -d '{"question":"Какой пароль Wi-Fi указан в правилах общежития ВШЭ 2017 года?","k":5}'
~~~

**Последние две команды не выполнялись с живым провайдером.** Не запускайте их
с настроенным оплачиваемым API без отдельного разрешения. Часть видео про реальный
ответ, цитирование и отказ пока является планом; нельзя подставлять заглушку.
В текущем бесплатном демо можно показать офлайн pytest: пустой retrieval даёт
точный отказ без вызова LLM. Это другой случай, чем найденный нерелевантный текст.

При будущей разрешённой записи проверить у ответа:

- После фактических утверждений есть номера [n].
- Sources содержат только процитированные документы и исходные страницы.
- Текст на странице действительно подтверждает утверждение.
- При отказе точная фраза «В документах нет ответа на этот вопрос.», sources=[].

Не показывать .env, ключи, личные документы или провайдерские реквизиты.
После записи добавить реальную ссылку в README. Скриншоты/видео не изготовлены.
